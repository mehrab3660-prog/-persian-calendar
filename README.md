# تقویم شمسی ۱۴۰۵ تا ۱۴۰۸

ساخته شده توسط محراب طلایی

فایل `calendar.ics` همه‌چیز را در یک تقویم دارد: تاریخ شمسی، قمری و میلادی، همه‌ی
مناسبت‌ها، تعطیلات رسمی (با 🔴) و یادآورها.

لینک اشتراک:

```
https://raw.githubusercontent.com/mehrab3660-prog/-persian-calendar/main/calendar.ics
```

## یادآورها
- ساعت ۸ شبِ قبل از هر تعطیل رسمی
- ساعت ۹ صبح، سه روز قبل از روز مادر، روز پدر، شب یلدا، چهارشنبه‌سوری، سپندارمذگان و نوروز

در آیفون، هنگام اشتراک گزینه‌ی **Remove Alerts** را خاموش کنید تا یادآورها کار کنند.
تقویم گوگل یادآورهای تقویم‌های اشتراکی را نشان نمی‌دهد.

## نکته‌ها
- تاریخ قمری بر پایه‌ی مناسبت‌های قمری تقویم رسمی ساخته شده است. برای سال ۱۴۰۸
  تقریبی است و ممکن است یک روز جابه‌جا شود.
- برای ساخت دوباره‌ی فایل: `python3 build_calendar.py SOURCE.ics .`
